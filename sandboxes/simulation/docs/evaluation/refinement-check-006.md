# Refinement check 006

The announcement slice preserves the attention-first model: an urgent update
is shown before routine information, while neither becomes an action item by
default. Expiration removes an announcement from the active view but does not
erase its stored history.

The refinement makes condominium ownership explicit on announcements and
filters mismatched tenant records. Equal-priority announcements now use their
stable identifier as a deterministic tie-breaker.
